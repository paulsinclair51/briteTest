## 2. Responsibilities

Maintainers are expected to:

- Review and approve changes that affect repository policy, release readiness, or
  critical framework behavior.
- Maintain the integrity of the default branch and protected branch workflow.
- Ensure contribution guidance, validation, and reporting remain consistent with
  the repository standards.
- Coordinate release validation and publication activities.
</details>
