**Branch**: Indicates the branch name. <span style="color:#66bb6a;font-weight:700">*</span> indicates this is the current branch.

<span style="color:#c62828;font-weight:700">!</span> after branch name indicates the name violates naming rules.

**Type**: Indicates branch is `local` or `remote`.

**Parent**: Parent branch reference for the row when applicable (for example,
`main` or `v1.0.0`).

**Status**: `clean`, `dirty`, or `not checked out` for local worktree
state, `synced` or `diverged` for tracked-branch state, or `unknown`.
For local branches, status includes `; auto-stash:N` when branch-matching
legacy auto-stashes exist (label:
`chcurrent-auto:BRANCH:TIMESTAMP`).

**Staged/Unstaged**: Counts of staged and unstaged files.

**Unpushed Commits**: Count of local commits pending sync for this branch.

**Ahead/Behind**: Counts of commits this branch is ahead of / behind
its tracked branch.

**PR**: Count of pending (not closed) pull requests.

**First Commit**: Approximate branch creation date, derived from the
first commit on the branch.

**Last Commit**: Date of the last commit on the branch.
