## Fork History

| **Date Time** | **Repository** | **Creator** | **Status** | **Email** |
|---------------|----------------|-------------|------------|-----------|

## Legend

- **Date Time**: The date and time for when entry was added.

- **Repository**: The name of the new repository.

- **Creator**: GitHub login of the creator.

- **Status**: `In Progess`, `Completed`, `Invalid`, `Deleted`.

- **Email**: The email address of the creator at the time
  creation.

## Notes

- A user may only make a new fork of this repository if the
  they have not made a fork already, or all the forks they
  have made have been deleted.
- This user or another user may make a fork of the new
  repository if it is public unless the rules for new
  repository are changed.
