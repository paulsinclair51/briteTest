# repository_history.md

Repository-level operational history for briteTest.

This file logs all repository-wide operations:
- Clone and fork operations (mkclone, rmclone, mkfork)
- Brand updates (rebrand)
- Release operations (release)

**Location**: `origin/main/logs/repository_history.md`  
**Scope**: Repository-wide (single source of truth)  
**Propagation**: Updated on main, propagated to all remote branches for visibility

## Legend

### Clone and Fork Operations
- **Date Time**: The date and time entry was created (UTC)
- **Operation**: `mkclone` (create clone), `rmclone` (remove clone), or `mkfork` (create fork)
- **Repository**: Repository name/URL
- **Actor**: GitHub username who performed the operation
- **Details**: Additional context (e.g., reason for removal, fork owner, etc.)

### Brand Updates
- **Date Time**: The date and time change was completed (UTC)
- **Brand**: New brand name
- **Initials**: Brand initials
- **Tagline**: Brand tagline
- **Actor**: GitHub username who performed the update

### Release Operations
- **Date Time**: The date and time release was created (UTC)
- **Version**: Version number (e.g., v1.0.0)
- **Branch**: Release branch (e.g., v1.0.0 for version branches)
- **Actor**: GitHub username who performed the release
- **Status**: `created` or `completed`
