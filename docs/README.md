## Subdirectories

- **branding/**: Monograms, logos, and document title logos as `*.svg`
  files and `*.png*` files generated from the '*.svg' files.

- **docx/**: Microsoft Word `*.docx` files generated from the
  `<repo>/docs/pdf/*.pdf` files.

- **md/**: Markdown `*.md` files (base/master documentation).

- **pdf/**: PDF formatted `.pdf` files generated from the
  `<repo>/docs/md/*.md` files.
