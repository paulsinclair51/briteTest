## Supported Versions

Security fixes are applied to the latest supported release and the active development branch when practical.

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Development branch | Yes, when practical |
| Older releases | No |

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when available. Include:

- A description of the issue and its potential impact.
- The affected version, branch, or commit.
- Reproduction steps or a proof of concept.
- Any suggested mitigation.

If private vulnerability reporting is unavailable, contact the repository maintainer privately through GitHub and request a confidential channel. Please allow maintainers reasonable time to investigate and prepare a fix before making details public.
